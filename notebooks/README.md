# 🚀 AI PriceOptima – Dynamic Pricing System

## 📌 Project Overview

AI PriceOptima is a machine learning-based dynamic pricing system designed to optimize product prices based on demand, inventory, and market conditions. The system helps businesses maximize revenue using intelligent pricing strategies.

---

## 🎯 Milestone 6: Deployment & Dashboard

In this final milestone, the complete pricing system is deployed using an interactive dashboard built with Streamlit.

---

## 🧠 Key Features

### ✅ User Input

* Current Price
* Inventory Level
* Discount
* Competitor Price
* Demand Forecast
* Units Ordered

---

### 💡 Price Recommendation

* Suggested Price (ML-based)
* Predicted Demand
* Expected Revenue

---

### 📊 KPI Visualization

* Revenue Comparison (Original vs ML)
* Demand Comparison
* Price impact on sales

---

### 🔍 Comparison Section

* Original Price vs Suggested Price
* Original Revenue vs Predicted Revenue
* Revenue Improvement (%)
